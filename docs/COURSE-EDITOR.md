# 퀴즈 잠금과 본문 편집

## 배포 시 한 번 할 일

기존 Neon DB의 SQL Editor에서 `db/migrations/002_course_editor.sql` 전체를 실행합니다. 기존 회원과 학습 기록은 유지됩니다. 새 DB라면 갱신된 `db/setup.sql`을 실행합니다. 두 파일 모두 다시 실행할 수 있습니다. 새 테이블 없이 배포하면 DB가 필요한 학습/편집 화면에 연결 오류가 표시됩니다.

## 운영자 사용법

Colab 링크 편집을 사용하려면 `db/migrations/003_colab_links.sql`도 실행하세요. 각 주차 본문 탭의 **Colab 실습 링크**에는 기본 노트북 주소가 표시됩니다. 수정하거나 비워서 저장할 수 있으며, 빈 값은 학생 실습 버튼을 숨깁니다. **기본 노트북 연결**로 복원할 수 있습니다. 잠긴 주차에서는 실습 링크를 표시하지 않습니다. Colab 실행은 사이트에 자동 기록되지 않습니다. [노트북 안내](../notebooks/README.md)

1. `ADMIN_EMAILS`에 등록된 학교 계정으로 로그인합니다.
2. `/admin` → **회차별 퀴즈 · 본문 관리** → 회차 편집으로 이동합니다.
3. 2–8주차의 퀴즈 탭에는 직전 주차의 내용으로 만든 2문항 초안이 있습니다. 번호, 문항 설명(Markdown), 선택 이미지 HTTPS URL, 관리자용 정답을 편집합니다. 이미지 파일 업로드/저장은 이번 버전에 포함하지 않습니다.
4. 학생에게 보여 줄 암호 조합 설명을 적습니다. 번호순 정답 이어 붙이기 버튼 또는 직접 입력으로 **실제 암호**를 지정합니다. 설명문은 자동으로 암호를 계산하지 않습니다. 미리보기로 정답이 노출되지 않는지 확인한 뒤 **학생에게 퀴즈 공개**를 체크하고 저장합니다. 초안은 저장 전까지 DB에 없으며 자동 공개하지 않습니다.
5. **학습 본문** 탭에서 Markdown을 수정하고 미리보기 → 본문 저장을 누릅니다. 저장은 바로 적용되며 Git push나 재배포가 필요 없습니다. 학생이 이미 열어 둔 페이지는 새로고침하면 반영됩니다.

본문의 제목·개념 체크 항목은 기존 frontmatter를 유지합니다. 체크 항목 ID를 바꾸지 않아 기존 진행도를 보존합니다. 원본 불러오기는 로컬 편집 내용을 원본 Markdown으로 바꾸며, 저장을 눌러야 학생 페이지에 적용됩니다. 다른 관리자가 먼저 저장하면 충돌 오류를 표시하므로 작성 내용을 복사한 뒤 새로고침하세요. DB 편집 내용은 Git에 자동 반영되지 않으므로 Neon 백업 대상으로 관리합니다.

## 학생 동작

- 0·1주차는 공개, 2–8주차는 기본 잠금입니다. 잠긴 주차의 제목·질문·개념·본문은 주차 페이지/로드맵/과제 목록에 전달하지 않습니다. 다음 주차 Preview와 내비게이션 제목도 잠금에 맞춰 숨깁니다.
- 자물쇠 → 암호 입력 대화상자 → 힌트 → `/quiz/회차`에서 직전 주차 복습 퀴즈를 봅니다. 로그인하지 않았다면 학교 로그인을 안내합니다.
- 직전 주차가 열려 있어야 다음 주차 퀴즈와 암호 제출을 허용합니다. 개념 체크 완료율과 잠금 해제는 별개입니다.
- 해제 기록은 계정별 Neon에 저장됩니다. 새 브라우저에서도 유지됩니다. 관리자는 모든 회차에 접근합니다.
- 퀴즈 비공개/암호 변경 후에도 기존 해제 기록은 유지됩니다. 기존 학습 완료 체크만으로 자동 해제되지는 않습니다.
- 암호는 Unicode NFKC 정규화 및 앞뒤 공백 제거 후 비교합니다. 대소문자·내부 공백을 구분합니다. 계정·회차별 15분 동안 최대 10회 시도할 수 있습니다.
- 실험실과 용어 사전은 열린 주차의 항목을 표시합니다. 최종 프로젝트는 8주차 해제 후 표시합니다.

## 본문에 인터랙티브 시각화 삽입

편집기의 **실험 삽입** 메뉴를 사용하면 커서 위치에 아래 블록이 들어갑니다.

````markdown
```visualization
gradient
```
````

지원 ID: `loss`, `gradient`, `hyperplane`, `feature`, `activation`, `cnn`, `residual`.

현재 실험은 React + TypeScript의 상태/수치 계산, SVG 그래프, HTML/CSS로 구현했습니다. Plotly, D3, Python, 외부 iframe을 사용하지 않습니다. 본문은 기존 실험을 재사용하며 임의 JavaScript/HTML을 실행하지 않습니다. 새로운 종류의 인터랙티브 시각화는 React 컴포넌트를 추가하는 코드 변경이 필요합니다. 일반 이미지와 KaTeX 수식도 Markdown으로 삽입할 수 있습니다. 실험 블록이 있는 본문은 상단의 기본 실험을 중복 표시하지 않습니다.

## 데이터/보호

`week_quizzes`: 관리자 정답, 공개 문항, 조합 안내, salted scrypt 암호 해시. 학생 페이지는 정답과 암호 해시를 조회/전송하지 않습니다.

`week_unlocks`: 회원·회차별 해제 시각. `quiz_attempts`: 시도 제한. `lesson_edits`: Markdown과 편집 버전. 회원 삭제 시 해당 회원의 해제·시도 기록은 cascade 삭제됩니다.

관리 API는 매 요청 관리자 확인과 same-origin 검사를 합니다. 학생 API는 서버 세션의 회원 ID만 사용합니다. 앱 화면의 학습 순서를 위한 기능이며, GitHub 저장소에 공개된 원본 강의까지 비공개로 만드는 기능은 아닙니다.
