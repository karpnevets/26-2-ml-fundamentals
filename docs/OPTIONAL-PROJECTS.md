# 선택 프로젝트 운영

관리자 → 선택 과제 관리(`/admin/assignments`)에서 제목, 소개, Markdown 본문, 완료가 필요한 주차, 공개 상태를 편집합니다. 저장 전 본문 미리보기를 확인할 수 있습니다. 동시 편집 충돌 시 최신 수정본을 덮어쓰지 않습니다.

초안 본문은 Git 저장소에 넣지 않습니다. 운영 DB에는 다음 중 하나로 최초 등록합니다.

- `website/.env.local`의 `DATABASE_URL`을 설정하고 `node scripts/import-optional-projects.mjs` 실행
- Neon SQL Editor에서 로컬 `.private-course/optional-projects.sql` 실행

신규 과제 6개는 모두 비공개입니다. 다시 실행해도 기존 운영자 편집과 공개 상태를 덮어쓰지 않습니다. 새 DB 스키마만 만드는 `db/setup.sql`에는 초안 본문이 포함되지 않습니다.

기존 DB에 실행합니다. 현재 개념 체크 목록도 함께 등록하며 기존 진행 기록과 본문은 삭제하지 않습니다. 초안 등록 후 이 버전의 사이트를 배포하세요.

학생은 공개된 프로젝트만 볼 수 있습니다. 과제 본문과 소개는 지정한 주차의 현재 개념 체크를 모두 완료하고 그 주차가 열려 있어야 서버에서 전달합니다. 관리자는 비공개 초안도 미리볼 수 있습니다. 이전 Check/Apply/Explore 문항과 기록은 주차 본문의 연습문제로 유지됩니다.

Week 0과 1은 시작 주차로 열려 있습니다. Week 2–8의 새 잠금 해제는 직전 주차 열람 권한과 계정에 저장된 개념 전체 완료를 모두 확인한 뒤 암호를 검사합니다. 로그인하지 않은 로컬 체크만으로는 잠금을 해제할 수 없습니다. 이미 해제한 주차는 개념 체크를 취소해도 다시 잠그지 않습니다. 프로젝트 본문은 현재 완료 여부를 확인하므로 체크를 취소하면 다시 제한됩니다.
